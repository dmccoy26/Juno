# Mission 6 — make Juno easier to use each day

## Outcome

A clear starting screen, daily work separated from setup, shorter task summaries, and safe exits from every planning form. Continue capabilities with a dated overview of saved tasks, blockers and local holds; keep task assignment and scheduling under human review.

## Scope

- Audit Chat, Plan, Schedules, Daily check-in, Memories, Model, TaskDock, Evidence, Connections and Computers. Record visual evidence separately from source inspection.
- Replace the crowded ten-item top switcher with grouped sidebar navigation and a current-page header.
- Add Today with saved TaskDock counts, due/blocked issues, local holds and direct actions into existing workflows. Show freshness, offline limits and partial-data errors.
- Give the planning sheet a visible Cancel action and pinned footer; group its fields and expose validation errors inside the sheet. Do not change saved data on Cancel.
- Make room issues easier to scan with expandable details and simple filters. Preserve clear unknowns and room-match uncertainty.
- Reduce repeated caution text, keep source details available on demand, and correct misleading model setup copy.
- Compile the native app; exercise date/task/room helpers and existing native/backend regressions appropriate to these changes. Attempt a visual pass across every screen at desktop/laptop-friendly widths. Preserve work-host records, certificate and pairing.
- Update build status and push source to GitHub. Installer packaging is a separate distribution step; do not claim the existing installer contains these changes.

## Audit evidence / limits

The supplied screenshots and earlier successful native captures show crowded horizontal navigation, large blank spaces, duplicated notices, full-length issue cards and a planning sheet with no visible cancel action. At mission start the native CUA connection failed (including after reset), preventing a new live screen sweep. Source inspection covers every workspace while native visual checks are retried. Do not claim all screens were visually tested unless that succeeds.

## Acceptance

Daily navigation stays distinct from setup; Today is useful with no LLM; an empty/offline/error state is truthful; task facts remain source-labeled; Cancel does not apply edits; saved data and pairing survive deployment; verification and incomplete visual checks are documented.
